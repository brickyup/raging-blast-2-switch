# Apply the GitHub makeover

This package contains documentation only. It is not the game installer.
Recreated on November 2, 2026 from the repository's current README; the old ZIP
was not recoverable. Existing technical instructions, credits, and license notes
are retained. Performance claims remain attributed to the project's documentation.

## Apply from Windows

1. Extract rb2-github-makeover.zip.
2. Open your local repository folder and copy the extracted contents into it,
   keeping the .github and docs folder structure. Replace README.md when asked.
   Keep all existing code, game-port folders, and license files.
3. Review the changes in GitHub Desktop, commit, and push.

Alternatively, open https://github.com/brickyup/raging-blast-2-switch/upload/main
and upload the extracted files and folders, preserving their paths. Do not upload
the ZIP. Check that the two templates appear under .github/ISSUE_TEMPLATE.
Use a new branch and pull request if you want to review before merging.

## No ZIP download: use the web editor

Open the companion github-web-edit.html locally. Each file has a copy button and
a link to its GitHub edit/create page. Paste the supplied content into that page,
then commit. The README can be edited at:
https://github.com/brickyup/raging-blast-2-switch/edit/main/README.md

For new files, use Add file > Create new file and enter the full relative path,
including folders. Add the banner at docs/assets/banner.svg so the README image works.

After applying, check the repository README and Issues > New issue. Both report
templates should be offered. No game build is needed for these documentation changes.
