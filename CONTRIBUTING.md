# Contributing

Thanks for helping improve Raging Blast 2 on Switch.

## Report a problem

Read the [troubleshooting table](README.md#troubleshooting), search existing issues,
then use the bug-report template. Include your release or commit, console model,
firmware, Atmosphère version, relevant settings, reproduction steps, and logs.
For performance reports, include the scene, internal resolution, clocks, and whether
the console was handheld or docked. Distinguish observed results from estimates.

## Suggest an improvement

Use the feature-request template to explain the problem and desired behavior.
For a substantial change, discuss the approach in an issue before starting work.

## Submit a change

1. Fork the repository and create a branch for one focused change.
2. Preserve existing credits and license notices.
3. Test the behavior you changed; describe your hardware and setup.
4. Open a pull request explaining the problem, the change, and the checks performed.
5. If you could not test on a Switch, say so explicitly.

Documentation fixes are welcome. For code changes, follow the style of nearby code.
Use the [build instructions](README.md#build-it-by-hand-linux-or-advanced-users)
with your own supported game copy.

Do not commit game assets, keys, generated game code, built NROs, or personal data.
Check logs before posting them. Keep reports respectful and specific.
